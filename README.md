# lamana
Repositori ini berisi source code untuk Tugas Akhir mata kuliah Pemrograman Berorientasi Objek (OOP) Informatika. Proyek ini adalah sebuah game Tower Defense / Strategi berbasis GUI (Graphical User Interface) di mana pemain dapat menyusun strategi pertahanan menggunakan berbagai karakter hewan yang diklasifikasikan berdasarkan golongannya (karnivora, herbivora, dll).
